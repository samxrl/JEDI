# New baselines

This directory contains three new safety baselines integrated with JEDI:

- [`CAST`](CAST/): conditional activation steering based on learned safety directions.
- [`Qwen3Guard`](Qwen3Guard/): periodic output monitoring with Qwen3Guard Gen/Stream.
- [`trajguard`](trajguard/): trajectory-level detection with SGS and conditional self-judging.

See each directory's README for configuration and usage details.
